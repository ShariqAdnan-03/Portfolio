A high-performance, responsive portfolio website designed to showcase my journey from Computer Science to Data Science & AI. Built with a **"Data-Driven" architecture**, allowing for easy updates without touching complex code.

---

## ✨ Features

- **🎨 Cyber Aesthetic:** Dark/Light mode support with a professional "Futuristic" UI.
- **🧠 Neural Network Background:** Interactive particle simulation representing AI connectivity.
- **⚡ Blazing Fast:** Built on Vite + React for instant load times.
- **📱 Fully Responsive:** Optimized for Mobile, Tablet, and Desktop.
- **📊 Data-Driven:** All content (Projects, Experience, Skills, Blogs) is managed in a single JSON-like file.
- **📄 Instant Resume:** Direct download link for my CV.

---

## 🛠️ Tech Stack

- **Framework:** React 18 + Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
